PROMPT 2 — 🌫️ DENSIFICATEUR SENSORIEL

Tu es un styliste narratif. Je vais te donner une scène de mon roman fantasy sombre. Réécris-la pour lui donner plus de présence sensorielle sans l’alourdir.

Consignes :
1. Ajoute seulement des détails sensoriels qui servent la scène.
2. Utilise 3 à 5 détails maximum parmi : odeur, son, température, texture, lumière, goût de l’air.
3. Chaque détail doit renforcer soit l’atmosphère, soit l’état intérieur du POV, soit la tension.
4. Évite les clichés du type « il faisait sombre », « l’air était lourd » si ce n’est pas incarné.
5. N’ajoute aucun élément de lore non présent dans le texte.

Format de réponse obligatoire :
- **Ce qui manque sensoriellement**
- **Ce que tu renforces**
- **Scène réécrite**

PROMPT 3 — 🎯 CLARIFICATEUR D’ENJEUX

Tu es un script doctor. Réécris la scène suivante pour que le lecteur comprenne immédiatement :
- ce que veut le personnage,
- ce qui l’empêche de l’obtenir,
- ce qu’il risque de perdre.

Consignes :
1. N’explique pas les enjeux de manière didactique.
2. Fais-les émerger par les actions, les choix, les tensions et les détails concrets.
3. Si la scène est émotionnelle, rends le conflit lisible sans casser la subtilité.
4. Si l’enjeu est flou, rends-le plus net dès les premières lignes.

Format de réponse obligatoire :
- **Enjeu actuel perçu**
- **Ce qui manque ou reste flou**
- **Scène réécrite**

PROMPT 4 — 👁️ FILTRE ABSOLU DU POV

Tu es un coach de voix narrative. Réécris la scène suivante pour que chaque ligne soit filtrée par le personnage focal.

Consignes :
1. Supprime toute phrase qui ressemble à une narration neutre, omnisciente ou touristique.
2. Chaque détail doit être vu, senti, jugé ou interprété selon la psychologie du POV.
3. Le vocabulaire doit être cohérent avec le personnage qui regarde.
4. Si le personnage est tendu, ironique, malade, paranoïaque ou froid, la phrase doit le porter.
5. Ne change pas les faits de la scène, change la manière de les percevoir.

Format de réponse obligatoire :
- **Ce qui sonnait trop neutre**
- **Ce que la voix du POV doit imposer**
- **Scène réécrite**

PROMPT 5 — 🩸 DURCISSEUR ÉMOTIONNEL

5. Garde le ton du récit.

5. Préserve la logique de la scène et le niveau social des personnages.

MODE D’EMPLOI CONSEILLÉ

- Utilise le PROMPT 1 quand une scène est trop longue ou trop molle.
- Utilise le PROMPT 2 si la scène manque de corps, d’air ou de matière.
- Utilise le PROMPT 3 si l’enjeu existe dans ta tête mais pas encore dans le texte.
- Utilise le PROMPT 4 pour éviter une narration trop neutre.
- Utilise le PROMPT 5 pour rendre une émotion plus juste et moins expliquée.
- Utilise le PROMPT 6 pour les scènes de confrontation ou d’intimité.
- Utilise le PROMPT 7 en fin de passe pour nettoyer sans vider.
- Utilise le PROMPT 9 pour faire passer le lore sans casser le récit.
- Utilise le PROMPT 10 pour renforcer la noirceur morale.
- Utilise le PROMPT 11 si une scène manque de crescendo.
- Utilise le PROMPT 12 comme dernier polissage de style.
- Utilise le PROMPT 13 quand tu veux une vraie passe complète sur une scène.

RÈGLES D’OR
- Une bonne phrase ne vaut rien si elle ralentit une mauvaise scène.
- Une scène forte doit avoir un enjeu lisible, un coût, et une trace émotionnelle.
- Le lore doit passer par le récit, pas se poser dessus.
- Le POV doit colorer chaque perception.
- Le style doit servir la tension, pas se regarder écrire.
